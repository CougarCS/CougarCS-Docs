# Discord Bot Introduction

The CougarCS Bot is our [Discord](https://discord.com/invite/Qd5RXjsM9v) bot used for the convenience of CougarCS's Discord users, members, tutors, and officers to access, update, and retrieve information indispensable to their needs. 

# Versatility in CougarCS Bot

__Role Specific Commands:__ Our bot's core functionality lies in its versatility to adhere to each role's needs. Once you, as a Discord user, are given your role(s), you will be able to access commands relegated to the role with the highest perms and below.
